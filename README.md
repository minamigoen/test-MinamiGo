# MinamiGo test — 美波まちのふしぎ帖

一般社団法人美波御塩の観光客・地元の方向け静的PWAレビュー版です。本番 `minamigoen/MinamiGo` は変更しません。伝承7件のカードは提供された **平成30年度（2018年度）の事業計画** の要約です。2026年のスキャン日と計画年度を区別しています。完成イメージを現在の施設・写真として使用していません。

## 起動・確認

Node 20以上（依存パッケージなし）、Python 3で動作します。

```sh
npm test
npm run validate
npm run build
npm run serve
```

`http://localhost:4173/` を開きます。GitHub Pagesの `/test-MinamiGo/` や独自ドメインの `/` にそのまま配置できます。`dist/` だけが公開物です。manifest、Service Worker、リンクは相対パスです。

## 実装内容

名前・説明・カテゴリの検索、カテゴリ絞り込み、カード/一覧/地図切替、端末内お気に入り、出典付き詳細、戻る/進む、3問の伝承資料クイズと学びスタンプ、インストール案内、初回読み込み/空/通信失敗/オフライン表示、更新通知を備えています。学びスタンプは訪問証明ではありません。7件のStreet Viewリンク、6件のMaps検索リンク、4件の施設周辺への徒歩経路検索があります。像・石・入口の位置と施設周辺の掲載地点を分け、現況や安全を保証しません。北向き地蔵の直接案内は避けています。現在地からの距離は施設周辺への直線距離です。

写真・原資料・地図・キャラクターの転載はしていません。SVGイラストとアイコンはこの試作で制作したもので、実景を表しません。Leaflet 1.9.4を同梱し、ライセンスを `assets/vendor/LEAFLET-LICENSE` に記載しています。Google APIキー、有料キー、アナリティクスは不要です。

## 管理・更新

[更新手順](docs/UPDATE.md) を参照してください。非公開Sheetsは編集元、公開JSONは承認済み行・列だけの別出力です。シートそのものや原PDFを公開する必要はありません。専用の非公開管理Sheetを既存アカウントに作成し、伝承7件と飲食店6件の計13件入力→既存コネクタ読取→公開JSON→テストブランチ反映の一周を確認済みです。管理SheetのIDは公開repoに保存せず、認証・共有権限・Apps Script公開デプロイは変更していません。

## ホスティング

既存テストリポジトリのみを使います。ユーザーが既存test表示を今回の試作へ置き換えることを承認したため、テストrepoのmainへ反映してPagesの配信を確認します。本番 `minamigoen/MinamiGo` にはマージしません。旧testソースは `backup/pre-walk-test-20261012`（`000cd52`）として保護しています。CIの `minamigo-test-preview` artifactも利用できます。公開状態と実URLは配信成功後に検証して案内します。

無料枠、地図の利用条件、現況確認、実機での残作業は [検証と制約](docs/REVIEW.md) を参照してください。

## 写真・飲食店・関連リンク

飲食店6件と種類フィルター、複数の関連リンク、写真URL/alt/出典/利用条件/クレジットの表示と許諾ゲートを追加しました。町/店舗写真の転載許諾は未確認なので、現在は「写真は準備中」の独自イラストです。写真欠落・取得失敗でも情報を利用できます。[更新項目と権利条件](docs/PHOTOS-FOOD.md)を参照してください。

## 美波飯との共通連携

飲食店は元の美波飯と同じ匿名公開API（37件）を正本として連携し、伝承7件・公開案内で照合した宿泊26件と合わせ70件です。既存6店舗のIDは維持します。起動時/明示更新で取得し、正常な元情報は端末で10分再利用。失敗時は直近正常データ、初回は公開時snapshotを表示します。元アプリ・元Sheet・権限は変更しません。元画像は権利未確認なので取り込みません。[正本/更新条件/ID対応](docs/SHARED-FOOD.md)を参照してください。

宿泊元表27件のうち、公開施設案内と照合した26件の名称・住所・出典リンクを掲載。元表の電話/座標/営業時間/画像は公開せず、1件は未確認で保留します。宿泊は実行時自動更新ではなく、既存接続で元表を取得し確認記録と照合してテスト公開します。[宿泊の更新と公開境界](docs/STAY.md)。
