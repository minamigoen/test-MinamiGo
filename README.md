# MinamiGo test — 美波まちのふしぎ帖

一般社団法人美波御塩の観光客・地元の方向け静的PWAレビュー版です。本番 `minamigoen/MinamiGo` は変更しません。7件のカードは提供された **平成30年度（2018年度）の事業計画** の要約です。2026年のスキャン日と計画年度を区別しています。完成イメージを現在の施設・写真として使用していません。

## 起動・確認

Node 20以上（依存パッケージなし）、Python 3で動作します。

```sh
npm test
npm run validate
npm run build
npm run serve
```

`http://localhost:4173/` を開きます。GitHub Pagesの `/test-MinamiGo/` や独自ドメインの `/` にそのまま配置できます。`dist/` だけが公開物です。manifest、Service Worker、リンクは相対パスです。

## 実装内容

名前・説明・カテゴリの検索、カテゴリ絞り込み、一覧/地図切替、端末内お気に入り、出典付き詳細、戻る/進む、3問の伝承資料クイズと学びスタンプ、インストール案内、初回読み込み/空/通信失敗/オフライン表示、更新通知を備えています。学びスタンプは訪問証明ではありません。7件のStreet Viewリンク、6件のMaps検索リンク、4件の施設周辺への徒歩経路検索があります。像・石・入口の位置と施設周辺の掲載地点を分け、現況や安全を保証しません。北向き地蔵の直接案内は避けています。現在地からの距離は施設周辺への直線距離です。

写真・原資料・地図・キャラクターの転載はしていません。SVGイラストとアイコンはこの試作で制作したもので、実景を表しません。Leaflet 1.9.4を同梱し、ライセンスを `assets/vendor/LEAFLET-LICENSE` に記載しています。Google APIキー、有料キー、アナリティクスは不要です。

既存テストリポジトリのレビュー用ブランチを使用します。このブランチをpushするだけでは、mainを配信するPagesは切り替わりません。CIの `minamigo-test-preview` artifact が配信ファイルです。本番マージ・Pages配信ブランチの変更はしません。
