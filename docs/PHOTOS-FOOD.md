## Sheetsで更新できる項目

既存の非公開管理Sheetの `spots` テーブルを `A1:AJ14`（13件・36列）へ拡張しました。元の27列と伝承7件の内容・承認・非公開メモ・型・書式を保持し、右に次を追加しています。管理SheetのID/編集URLは公開repoへ入れません。

| 列 | 内容 |
| --- | --- |
| AB photoUrl | 掲載権利と外部URLでの表示条件を確認したHTTPS画像URL |
| AC photoAlt | 200文字以内の代替テキスト |
| AD photoSource | 写真の出典のHTTPS URL |
| AE photoLicense | 確認済み利用条件（選択式） |
| AF photoCredit | 作者/提供者など必要なクレジット |
| AG relatedLinks | `[{"label":"表示名","url":"https://…"}]` のJSON配列、最大8件 |
| AH foodType | `カフェ・イタリアン` など。「・」で区切った各種類で絞り込み可能 |
| AI officialCheckedAt | 公式/掲載元ページを読んだ日。記事更新日や営業中の保証ではない |
| AJ photoApproved | 掲載権利・利用条件・外部画像表示を確認済みの場合のみTRUE |

行の `publicApproved` がTRUEでも、`photoApproved` がFALSEなら写真URLと写真メタデータ5列は公開JSONへ出力しません。掲載する場合はURL・代替テキスト・出典・クレジット・利用条件をすべて入力して承認します。利用条件はCC BY 4.0/CC BY-SA 4.0/CC0 1.0/掲載許諾確認済み/管理者撮影（掲載権利確認済み）から、事実に合うものだけを選びます。空欄や「未確認」を公開承認しないでください。公開画像だから自由に使えるとは判断しません。

写真/関連リンクは公開HTTPS URLのみ。認証情報付きURL、IPリテラル、localhost/内部ホスト、標準以外のポート、javascript/data URLは拒否します。リンクラベル・クレジット・altはDOMのtextContent/プロパティで設定し、データをHTMLとして実行しません。不正データは同期を停止し、前回正常JSONを保持します。

店舗の `mapScope=name-address` は座標の確認と区別します。住所・検索名・説明が必要で、未検証の座標は付けられません。この範囲では名称・住所による徒歩経路を作れます。`locationVerified` がFALSEの座標と、一般の未確認地点の経路は従来どおり抑止します。

## 表示・オフライン

カード/詳細に写真・代替表示、出典/利用条件を表示。カード画像はlazy loading・async decoding・寸法予約でモバイルの負担を抑えます。写真取得失敗・欠落・オフラインは代替表示に戻り、本文と操作は利用できます。外部写真は独立した提供元へ通信し、Referrerを送りません。写真をアプリのService Workerへ保存/先読みしないため、オフライン写真表示は保証しません。外部URLの表示条件も権利確認に含めてください。

今回のService Worker cache versionは `20261013-photos-food-2`。新しいmedia moduleも同一ホストのapp shellに含め、更新通知から版を切り替えます。お気に入りと学びスタンプの保存キーは維持します。
