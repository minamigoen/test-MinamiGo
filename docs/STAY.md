# 宿泊の公開境界と更新

元の宿泊用Google Sheets `stay`（27件）を既存接続で読み取り専用で確認しました。共有設定・権限・元表は変更していません。匿名CSV取得は成功せず、宿泊の既存公開APIも確認できません。元表ID・全列・内部管理項目は公開repoに保存しません。

町の[公開施設案内](https://www.town.minami.lg.jp/institution/result.html?category_ids%5B%5D=11431&category_ids%5B%5D=11432&category_ids%5B%5D=11433)と観光協会の[ほたる村](https://www.minamikankou.jp/%E6%B3%8A%E3%81%BE%E3%82%8B/%E3%81%BB%E3%81%9F%E3%82%8B%E6%9D%91)・[花乃宿](https://www.minamikankou.jp/%E6%B3%8A%E3%81%BE%E3%82%8B/%E8%8A%B1%E4%B9%83%E5%AE%BF)の公開名称・住所を、元表のNO・名称と照合し26件掲載しています。住所の差異は公開施設案内を優先。モビレージキャンプ場1件は独立した施設としての確認を保留しています。

宿泊元表の住所・座標・電話・備考・時間・休日・URL/SNS・画像は取り込みません。電話や住所に別の公開情報との食い違いもあるため、未検証情報を自動で公開する方式にはしません。宿泊の地図は名称・公開住所検索で、未検証の座標ピンを表示せず、Google Maps検索と徒歩経路の入口を提供します。最新料金・チェックイン・営業状況は施設の公開案内で確認してください。写真の転載権利は確認できていないため掲載0件です。

`data/stay-review.json` は公開項目の確認記録で、第二の編集用台帳ではありません。元NO/名称との対応、公開出典、確認日、確認した公開名称/住所だけを持ちます。新規行・変更項目は公開根拠を再確認してこの記録へ承認します。元シートの基本情報の編集は元シートで行います。

## 更新操作（既存接続、非公開のまま）

1. 既存Sheetsコネクタで元 `stay!A1:L50` をUNFORMATTED_VALUEとして読取り、返却されたvaluesをrepo外の非公開作業パスへ保存。共有/OAuth/キー追加は不要です。
2. 公開案内と照合して確認記録を更新。元表だけの変更、新規行、画像・備考・内部列は公開しません。未確認は保留します。
3. `node scripts/sync-stay.mjs /private/path/stay-range.json`。NO重複・名称の変更・欠落・出典URL不正は終了コード1で停止し、前回正常データを維持します。
4. `npm run sync:food`、`npm test`、`npm run validate`、`npm run build`。原表の出力をcommitせず、派生した公開JSONと確認記録のみテストrepoへ反映。
5. SW version更新、test公開、実URL確認。宿泊の変更は**検証後の公開時**に追従します。飲食店37件は既存匿名公開APIから実行時に追従します。

カード・一覧・地図の表示切替は検索/カテゴリ/料理種類を維持します。宿泊カテゴリの地図ビューは座標を作らず、名称一覧から詳細とGoogle Mapsへ進めます。飲食と宿泊を営む同一施設も、元NO体系が別なのでサービス別の項目を維持し、同一予約サービス・同一営業営業時間と決めつけません。
