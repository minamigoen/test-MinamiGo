# 観光追加と地図初期表示（2026-10-14）

町のMINAMI TIME（見る12・祭り6・体験6）と指定元資料フォルダの観光・イベント・体験表を照合。町の説明の転載ではなく、事実の短い独自要約・出典リンクとして整理しました。

## 件数・統合

- 新規20件（自然4・文化5・物産1・体験4・祭り6）を追加、既存88IDを保持し全108件。
- 大浜海岸・産卵・だるま朝日は同じ海岸へ統合。薬王寺の名水・寺院体験を1施設へ統合。
- 日和佐日和は旧八嶋電機店舗（heritage-373003）の関連案内・検索名へ統合し、二重登録なし。
- 元イベント表でタスク「削除」・休止扱いの芸題踊りは新シートの確認記録に残し、出力とアプリへは入れない。

## 座標と写真

新規20件の12参考点・8位置保留を掲載。全体の通常表示ピン94。短縮Mapの遷移先にある対象POI !3d/!4dを採用し、表示中心@座標は施設の点に使わない。施設代表点も「推定位置・入口未確認」と表示。阿波沖海戦小公園は元表の参考座標であることを明記。

保留8件は祭り6件、桜街道、人力企画。桜街道の町Mapは南阿波サンラインと同じリンクなので不採用。人力企画の町MapのPOI名はクーランマランで、同一性未確定なので座標は保留（名称・所在地・電話は事業者公式Aboutで照合）。祭りの会場と開催年の日程は、過去の定例案内を現在の確定情報として使わない。

薬王寺の町watch案内に温泉のMap・電話・営業時間が混在するため、寺院は体験欄の薬王寺POIと公式電話を採用。日和佐城の住所は町施設ガイドの445-1を採用。いずれも確認記録に差分と根拠を保存。

町サイトの[利用条件](https://www.town.minami.lg.jp/docs/183.html)は画像等の無断転用を許可していません。既存の飲食・宿泊許諾を新しい観光素材へ広げません。町の新規写真は転載・読込みなし。新規20件のうち大浜海岸だけ、既に確認済みの同一CC BY 2.0写真（na0905、2010年1月）を出典・利用条件付きで再利用。19件の新素材は許諾確認待ち。

## 新シートと取込

指定フォルダの新しいネイティブGoogle Sheetをeatのコピーから作成。既存eat/stay、元資料、共有設定を編集していません。

- sightseeing!A1:L22：eatと同じ12列、ゼロ埋めNO。管理表のA列が「削除」でない行をQUERYする同じ規則。
- 観光スポット一覧_フォーマット!A1:AH23：eatと同じ34有名列、22管理行。外部IMPORTRANGEは複製先だけ除去し、確認済みの観光データを記入。
- 確認記録!A1:R23：出典、アプリID、統合先、元表座標と採用座標、確度、保留理由、画像条件。

既存認証のコネクタで出力を読戻し、数式エラーなし・21出力行・先頭ゼロ・座標・画像方針を確認。Googleの100%表示で全3タブを確認。新しい公開APIやSheetの匿名共有は不要で、アプリは確認済みの公開JSONだけを配信します。Sheet編集だけでアプリが即時変更される仕組みは追加していません。

更新はコネクタで同じ12列の値を取得し、no/name/address/lat/lng/tel/description/hours/closed/url/sns/imageのJSONとしてローカルに保存後：

```sh
node scripts/sync-sightseeing.mjs <connector-readback.json>
npm run sync:local
npm test
npm run validate
npm run build
```

新しい行・名称・座標・CC写真の変更はレビュー表との一致確認が必要。未確認画像はURLが存在しても読込まない。元シートID・認証・非公開列は公開JSONへ出力しません。

## UIと検証

初期表示は美波町中心の地図（全カテゴリではズーム12）。広域の地点は一覧から選ぶと同じ倍率で中心へ移動する。「条件を変更」で検索・カテゴリへ戻れる。カードと一覧は明示選択のURLを保持して再読込できる。スマホの非モーダル下部パネル・PCの一覧並列・連続再選択・写真・背景切替を維持。座標のないカテゴリは空白地図を置かず一覧を表示し、詳細を通常ダイアログで開く。

`tests/live-tourism.py --local` と公開URLの `tests/live-tourism.py` は390/1440pxで初期地図、108件/94ピン、新規20件の詳細・12参考点/8保留、祭り6件の一覧、既存遺産1件への統合、カード/一覧/地図と再読込、CC画像の実寸法、未許諾町写真の通信なしを検証。既存地図UX・全飲食宿泊写真・PWA検証も継続。
