## URLと再現

- 全件地図：`./`
- 飲食：`?category=eat&view=map`
- 宿泊：`?category=stay&view=map`
- 暮らし：`?category=life&view=map`
- 年間行事：`?year=2026#events`

検索、表示切替、カテゴリ、選択施設はURLに反映し、再読込・履歴の戻る／進むで復元する。共有ダイアログの「今の検索・カテゴリ・表示条件を含める」で現在の条件をQRへ含められる。位置情報とお気に入りは含めない。検索語はURL・ブラウザ履歴・共有先・再読込時の配信元通信に含まれ得る。旧ハッシュ形式も読める。
