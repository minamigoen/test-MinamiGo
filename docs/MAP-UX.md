# 地図から続けて探す（2026-10-14）

スマホは地図内の下部に非モーダルの詳細パネルを表示。縮小・展開・閉じるができ、他のピンを続けて選べます。ピン押下はズーム・中心位置を変更しません。PCはスクロールできる一覧と地図を並列表示し、選択をハイライトします。一覧選択は地点へパンしますがズームは保持。写真・出典・お気に入りは維持。

確認手順：地図→食べる→複数ピンを続けて押す→縮小/詳しく見る→閉じる→一覧から再選択。Enter/Spaceでピン、Enterで一覧、Escapeで閉じる（ピンから開いた場合は同じピンへフォーカス）。地図/空中写真の切替でも位置・ズームを保持。スマホの一覧は地図下。

美波遺産12件は既存ID・名称を照合し公式公開地図の座標へ更新。旧4参考点は同一レコード内で置換し重複させません。施設代表点で入口・建物中心の別、内部見学は未確認。HWDT外観のみ2025年2月Street Viewで照合済み（入口座標は未測定）。座標根拠は `data/heritage-coordinate-evidence.json` と各詳細の関連リンク。写真許諾は美波遺産に拡張しません。

検証：`npm test`、`npm run validate`、`npm run build`、`python tests/map-browser.py`、`python tests/live-map-ux.py --local`。公開後は `python tests/live-map-ux.py` と `python tests/live-photos.py` が390/1440pxで実画像寸法、連続ピン選択、一覧連動、閉開、キーボード、美波遺産12ピンを確認し `live-evidence/` に結果・画面を保存。CIでも公開URLの同検証を実行。

既存インストール版は「更新して再読み込み」で新しいPWAバンドルへ更新します。本番repo、元Sheet、共有権限、認証は変更しません。


## パワースポット座標追補

既存12IDへ位置調査を統合。参考座標10件のうち、地図の「閉業」表示・現存未確認の日和佐陣屋的石は旧位置資料として座標を保持する一方、通常ピンとMaps/徒歩ナビを非表示。表示は9参考ピン、座標保留は2件。後山の大岩は山上の参考点で、登山口と混同せず経路案内を無効化。北向き地蔵なども入口・私有地境界は未確認と明記。

蛇責めの石と井ノ上の不動明王は2025年2月Street Viewで対象物を原典写真と照合。寺・神社の3点は施設代表点で個別石像・石の位置と区別。他の周辺Street Viewや投稿写真の照合は対象物確認と混同しない。旧5仮名は同じIDのまま調査名・候補名へ更新し、原典判読と所在の不確実性を説明。写真転載はなし。`data/power-coordinate-evidence.json` に全件の根拠・確度・表示推奨を保存。

公開URL検証は390/1440pxで12一覧・9ピン・3非表示地点・山上と旧位置のナビなし・2件の対象物Street View照合表示を確認する。
